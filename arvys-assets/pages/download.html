Arvys Code

Installez l'application sur tous vos appareils — ou utilisez-la directement dans le navigateur.

Ordinateur (PC / Mac / Linux) navigateur

Rien à installer : ouvrez l'adresse du site, tout fonctionne (terminal, vocal, fichiers).

Astuce : dans Chrome/Edge, l'icône « Installer » dans la barre d'adresse transforme l'app en fenêtre dédiée.

Android (téléphone & tablette) APK

  1. Téléchargez l'APK ci-dessous.
  2. Ouvrez le fichier téléchargé ; Android demandera « autoriser les sources inconnues » pour votre navigateur → autorisez (l'APK est signé en debug, usage personnel).
  3. Installez, puis ouvrez Arvys Code.
  4. Au premier appel vocal : acceptez la demande d'autorisation micro.
Télécharger arvys-code.apk

Pas d'APK ? La PWA marche aussi : menu ⋮ du navigateur → « Ajouter à l'écran d'accueil ».

iPhone & iPad PWA

  1. Ouvrez l'adresse du site dans Safari.
  2. Bouton Partager (carré avec flèche) → Sur l'écran d'accueil → Ajouter.
  3. L'app apparaît en plein écran avec son icône, comme une app native.

Le micro : Réglages iOS → Safari → Micro → Autoriser. Les apps iPhone installables (.ipa) exigent un compte développeur Apple — la PWA donne la même expérience sans ce prérequis.

Vocal & superposition (Android)

Si la demande d'autorisation micro n'apparaît jamais, une appli « superposée » (filtre lumineux, bulles de chat, lecteur flottant) bloque l'écran : Réglages → Applications spéciales → Affichage par-dessus → désactivez ces applis, rechargez la page, réessayez.
