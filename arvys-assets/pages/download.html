Android (Téléphone & Tablette) PWA & APK

Deux modes d'installation au choix :

  1. Installation directe (PWA recommandée) : Cliquez sur « Installer l'application » ci-dessous pour ajouter Arvys Code en plein écran natif sans télécharger de fichier externe.
  2. Application packagée (APK) : Vous pouvez également télécharger et installer le fichier APK complet.
Télécharger arvys-code.apk

Si le bouton PWA n'apparaît pas : ouvrez le menu ⋮ de Chrome → « Ajouter à l'écran d'accueil ».

iPhone & iPad PWA Safari

  1. Ouvrez cette adresse dans Safari sur votre iPhone.
  2. Touchez l'icône Partager (carré avec la flèche vers le haut en bas de l'écran).
  3. Faites défiler et sélectionnez Sur l'écran d'accueil.
  4. Touchez Ajouter en haut à droite.
  5. Arvys Code apparaît sur votre écran d'accueil avec son icône dédiée, en plein écran sans barre d'adresse.

Microphone vocal sur iOS : Réglages → Safari → Microphone → Autoriser.

Vocal & superposition (Android)

Si la demande d'autorisation micro n'apparaît jamais, une application superposée (filtre de nuit, bulles de discussion, enregistreur d'écran) bloque l'écran : Paramètres → Applications → Accès spécial → Affichage par-dessus d'autres applications → désactivez-les temporairement, rechargez, et validez le micro.
